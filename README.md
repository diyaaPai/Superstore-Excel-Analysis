\# Superstore Excel Analysis



\## Project Overview



This project analyzes the Sample Superstore dataset using Microsoft Excel to identify sales, profit, customer segment, regional, shipping, and sub-category performance.



\## Objective



The objective of this project is to clean and analyze the Superstore dataset and build an interactive Excel dashboard that highlights key business trends and performance areas.



\## Tools Used



\- Microsoft Excel

\- Power Query

\- PivotTables

\- PivotCharts

\- Slicers

\- Excel formulas and functions



\## Data Preparation



Power Query was used to prepare the dataset, including:



\- Checking and handling data types

\- Converting Order Date and Ship Date to proper date formats

\- Checking for missing values

\- Checking for duplicate records

\- Creating Year and Month-related date fields

\- Reviewing unusual and negative profit values



\## Analysis Performed



The analysis covers:



\- Sales trends over time

\- Sales by region

\- Profit by shipping mode

\- Sales and profit by customer segment

\- Sales and profit by sub-category

\- Average discount

\- Negative-profit sub-categories



\## Dashboard



The interactive dashboard includes:



\- Total Sales KPI

\- Total Profit KPI

\- Total Orders KPI

\- Average Discount KPI

\- Sales Trend Over Time

\- Shipping Mode Analysis

\- Profit and Sales by Sub-Category

\- Segment Analysis

\- Regional Sales Performance

\- Interactive slicers for Region, Category, Segment, and Ship Mode



\## Key Insights



\- Sales show stronger performance toward Q4.

\- Standard Class generated the highest total profit among shipping modes.

\- Technology generated the highest profit among the major categories.

\- Furniture contained sub-categories with negative overall profit.

\- Consumer generated the highest sales and profit among the customer segments.



\## Dataset



The project uses the Sample Superstore dataset for analysis and dashboard development.



\## File



`Superstore\_Excel\_Analysis.xlsx` contains the cleaned data, PivotTables, analysis, and interactive dashboard.
